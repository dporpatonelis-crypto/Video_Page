# Βιβλιοθήκη δραστηριοτήτων «Παρακολουθώ – Συμπληρώνω – Ταξινομώ»

Αυτοτελή HTML μαθήματα για σύντομες βιογραφικές διαδρομές. Κάθε δραστηριότητα συνδυάζει τρεις προβολές βίντεο, επιλογή ρημάτων, ταξινόμηση γεγονότων και τελική μικρή περίληψη.

## Περιεχόμενο

- **Πατέρες της Εκκλησίας:** Αθανάσιος, Βασίλειος, Γρηγόριος ο Θεολόγος, Ιωάννης ο Χρυσόστομος, Κύριλλος Αλεξανδρείας, Μάξιμος Ομολογητής, Συμεών ο Νέος Θεολόγος, Γρηγόριος Παλαμάς, Ιωάννης Δαμασκηνός, Σωφρόνιος Σαχάρωφ.
- **Παλαιά Διαθήκη:** Μωυσής, Αβραάμ, Δαυίδ, Προφήτης Ηλίας.
- **Καινή Διαθήκη:** Ιωάννης ο Βαπτιστής, Ιωάννης ο Ευαγγελιστής, Απόστολος Πέτρος, Απόστολος Παύλος.

Το index.html είναι ο κατάλογος της βιβλιοθήκης. Κάθε μάθημα βρίσκεται στον αντίστοιχο φάκελο του lessons/.

## Βίντεο και λειτουργία

Τα βίντεο **δεν αντιγράφονται εδώ**. Κάθε HTML χρησιμοποιεί απευθείας τον υπάρχοντα σύνδεσμο MP4 του [Digital Book](https://dporpatonelis-crypto.github.io/interactive-books/Digital_Lessons/). Οι μικρογραφίες φορτώνονται επίσης από το Digital Book, όπου υπάρχουν. Έτσι το αποθετήριο περιέχει τα μαθήματα και όχι αντίγραφα μεγάλων μέσων.

Οι επιλογές και η πρόοδος κάθε μαθήματος αποθηκεύονται τοπικά στη συσκευή. Σε αποτυχία φόρτωσης του online βίντεο, υπάρχει δυνατότητα επιλογής τοπικού αρχείου βίντεο από τη συσκευή.

## Δημοσίευση

Το αποθετήριο είναι έτοιμο να δημοσιευτεί ως GitHub Pages από τον κλάδο main, με φάκελο / (root). Η δημοσίευση δεν ενεργοποιείται από αυτή την αλλαγή.
